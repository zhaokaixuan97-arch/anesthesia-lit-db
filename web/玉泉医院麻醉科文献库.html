这个库是什么？（点开看）

这是咱们麻醉科自己整理的文献库，把找到的麻醉相关文献集中放在一起，方便随时查。

每篇文献包含两部分：

  • 题录：标题、作者、期刊、年份、DOI，都从 PubMed 自动抓取，不会有错。
  • 笔记：科里同事写的 PICO、主要结果、局限性、对我们科的参考价值。

重要提醒：本库只收录已发表文献的公开信息，不含任何患者信息。笔记仅供循证参考，不能替代临床判断，关键结论请核对原文。

给会用 AI 的同事：怎么把文献库接到 AI 里

本库自带一个 MCP 服务端（mcp/server.py），装好后可以直接问 AI："我们库里关于术后谵妄的证据有哪些？"，AI 会去查库并带 DOI 回答。

配置方法（以 Claude Desktop 为例）

1. 找到配置文件 claude_desktop_config.json（Windows 在 %APPDATA%\Claude\）。

2. 加入下面这段（把路径换成文献库实际所在目录）：

{
  "mcpServers": {
    "anesthesia-lit-db": {
      "command": "python",
      "args": ["文献库目录\\mcp\\server.py"]
    }
  }
}

3. 重启 AI 客户端即可。

能用哪几个功能

  • search_literature：按关键词、主题、类型、年份检索
  • get_paper：取某篇的完整题录与笔记
  • list_topics：看主题覆盖情况，发现空白方向
  • library_stats：全库统计
  • find_related：找主题相近的文献

详细说明见仓库里的 docs/AI接入指南.md。

➕ 添加文献（填一个 DOI 就行）

在下面填 DOI 或 PMID，点按钮会跳到 GitHub 的表单；确认提交后，机器人会自动去 PubMed 抓题录、建目录、写笔记模板，约 1 分钟后网页自动更新。

需要登录 GitHub 账号，建议在电脑上操作——手机微信里登录 GitHub 容易卡住。
